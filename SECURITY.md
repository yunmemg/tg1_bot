# Security Policy

## Reporting a vulnerability

Do not disclose credentials, Telegram Session files, payment secrets, private
keys, or personal data in a public issue.

Contact the maintainer privately through `@qinyubo` and include only the
minimum information needed to reproduce the problem. Revoke any credential
that may already have been exposed.

## Supported version

Security fixes target the latest published release.
