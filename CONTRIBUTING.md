# Contributing

Contributions are welcome.

1. Do not commit real configuration, tokens, credentials, Session files,
   runtime JSON data, logs, caches, or generated release archives.
2. Keep user-visible Chinese and English localization keys and placeholders in
   sync.
3. Run `python -m pytest -q` before submitting a change.
4. Preserve the MIT license and copyright notices.

By contributing, you agree that your contribution is provided under the MIT
License.
